# week3-layout-hw
Improves a starter HTML page by adding readable layout constraints, consistent spacing, and responsive behavior using CSS.

## 1. Design goals
The goal of this assignment was to improve readability by constraining line length, creating consistent spacing, and making the layout usable on smaller screens.

## 2. Three biggest layout changes
1. Added a max-width container to prevent edge-to-edge text.
2. Introduced consistent margin and padding spacing across sections.
3. Improved by readability by increasing line-height and paragraph spacing.

## 3. Responsive behavior implemented
The teaser cards stack vertically on smaller screens and switch to a side-by-side column layout at wider screen sizes using a CSS media query.
